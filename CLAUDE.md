# mail-sec-audit: правила для агента
- По умолчанию только чтение. Изменения только в --interactive.
- Внешние команды идут только через runner с allowlist. Новая команда = запись в таблице + тест.
- Запрещено: eval, shell=True, команды mailinabox и update.sh, restart/reload, изменения пакетов и конфигов, чтение секретов.
- Нет данных = UNKNOWN. Неприменимо = N/A. Отсутствие ошибок не равно OK.
- Каждый finding имеет стабильный ID, источник и доказательство.
- Зависимый от стека код только в stacks/.
- Весь текст для человека идёт через каталоги ru и en.
- Реальные клиентские данные в репозиторий не попадают.
- Тесты запускаются в Linux: WSL2 или контейнер. CI: mypy --strict, ruff.
- Один этап = одна ветка и один PR.
